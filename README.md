# HR-analytics-Tableau-dashboard
An interactive Human Resources Analytics Dashboard built in Tableau to analyze workforce data and provide insights into employee demographics, employment status, departments, salaries, performance, and employee records.
The project allows users to explore HR data through interactive dashboards, filters, calculated fields, and navigation between high-level workforce insights and detailed employee records.

🔗 Live Dashboard:
https://public.tableau.com/app/profile/tanjima.hossain4365/viz/tableauHRproject/Dashboard1

**Project Overview**

Human Resources departments work with large amounts of employee data that can be difficult to analyze efficiently. This project transforms employee data into an interactive Tableau dashboard that provides a clear overview of the workforce and allows users to explore individual employee records.
The dashboard is divided into two main sections:
HR Overview
Employee Records
Users can navigate between dashboards and interact with the data using filters and interactive visualizations.

**Dashboard Preview**

HR Dashboard | Overview
The Overview dashboard provides a high-level summary of the organization's workforce, including employee status, demographics, department distribution, geographic distribution, education, performance, and salary analysis.

Employee Records
The Employee Records dashboard provides a detailed view of employee information and allows users to filter and explore the workforce based on multiple criteria.
